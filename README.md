# AI Chat Interface Starter Code

A ChatGPT/Claude style dark themed AI streaming assistant interface built with React.

## Features
- **Streaming Response Engine**: Simulated character-by-character response typing using `setInterval`.
- **Interactivity Controls**: Stop response generation midway, clear chat history, or copy AI messages to clipboard.
- **Prompt Suggestions**: Starter query templates on empty state.
- **LocalStorage Persistence**: Auto-saves user conversation history.
- **Typing Indicator**: Animated pulsing typing dots when waiting for response.
